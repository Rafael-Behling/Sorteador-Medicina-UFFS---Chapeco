# CampeANATO - Sorteador e Painel

Sistema HTA (HTML Application) para sorteios e controle de ranking no CampeANATO.

## Estrutura
- Sorteador.hta - Tela do projetor (sorteio de temas/números)
- Painel.hta - Painel de controle (grupos, pontos, cronômetro)
- SONS/ - Arquivos de áudio
  - som da roleta girando.wav
  - pergunta_trunc.wav / sino.wav (sino nos últimos 2 segundos)
- playsound.exe - Helper para reprodução de áudio
- TOPICOS/, NUMEROS/, FUNDO/ - Imagens
